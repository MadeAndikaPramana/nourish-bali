## Fonts

Self-hosted via Fontsource, all under the SIL Open Font License 1.1:
- **Archivo** (Omnibus-Type), display
- **Plus Jakarta Sans** (Tokotype, Jakarta), body
- **Instrument Serif** (Instrument), accents

## Code and effects

- Hero shader: [Paper Shaders](https://github.com/paper-design/shaders) (`@paper-design/shaders-react`, Apache-2.0).
- Motion: [Motion](https://motion.dev) (MIT), smooth scroll: [Lenis](https://github.com/darkroomengineering/lenis) (MIT).
- Some interaction patterns are adapted from free [Skiper UI](https://skiper-ui.com) components (scroll-drawn SVG path,
  text roll navigation, progressive blur) and rewritten for this site.
